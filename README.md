# Strictons homepage rebuild

Static production-ready homepage concept for Strictons Signature Hotel Guides.

## Run locally
Open `index.html` directly, or serve the folder with any static server.

## Temporary media
The homepage intentionally uses temporary third-party stock media while the real Strictons guide and hotel photography are being prepared. Replace the hero video and Unsplash images before final production launch.

## Direction
Hospitality-first editorial design; restrained typography; product-led story; clear hotel proposition; no invented testimonials, partners, usage statistics or results.
